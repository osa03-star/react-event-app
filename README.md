イベントの申し込みのデモが行えるアプリです

## 使用技術

- React
- Typescript
- Vite
- CSS

## 概要
[こちら](https://react-road.b13o.com/challenges/event-listing-app) のチャレンジ内容を
実装しました。
メールアドレスで登録できるイベントの申し込みのデモが行えるアプリです。
*DB使用していないため、入力されたメールアドレスはどこにも保存されません。
*レスポンシブは実装していません。
